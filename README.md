# Evacuation Planning System

A real-time evacuation planning and tracking system that optimizes vehicle-to-zone assignments for disaster response scenarios using genetic algorithms.

## Deployment

This project is automatically deployed via GitHub Actions to Azure Web App.

**Production URL:** https://evacuationplanning-dsbngmdbh0hhcadp.southeastasia-01.azurewebsites.net/
